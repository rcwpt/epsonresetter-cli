## 2. Standards & Protocol References

This software implements public hardware communication standards and reverse-engineered protocol formats:

- **IEEE Std 1284-2000:** Standard Signaling Method for a Bi-directional Parallel Peripheral Interface for Personal Computers.
- **IEEE Std 1284.4:** Data Communication Protocol for Personal Computer Printers and Peripherals (Packet Framing & Channel Multiplexing).
- **Epson ESC/P-R (Raster) Command Specifications:** Public raster command specifications published by Seiko Epson Corporation for Linux and Unix drivers (Gutenprint / ESC/P-R open-source printer filter).
